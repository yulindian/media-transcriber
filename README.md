# media-transcriber

**下载视频，或把视频、播客与本地录音整理成有总结的 Markdown 全文稿。**

当前版本 **0.4.0** · [更新记录](CHANGELOG.md)

## 能做什么

- 提取完整讲话，修正有依据的错字，补标点、整理自然段。
- 单人讲话直接分段；多人对话区分说话人，无法确定身份时使用编号。
- 短内容给一段核心总结；播客等多主题内容按话题给时间轴总结。
- 正文不显示时间轴或“待核对”等行内标记，方便直接阅读。
- 同时保存机器原稿、修改记录和字幕，方便回看。
- 支持多条链接依次处理，中断后可继续。

支持小红书、小宇宙、抖音、视频号、B站、YouTube、媒体直链和本地音视频。能否取得内容取决于平台权限和入口，不保证所有链接都可下载。图文笔记、图片文字和网页文章不属于音视频转录，应先区分内容类型。

## 让 Agent 安装

把下面这段发给你使用的 Agent：

```text
请安装这个音视频转录技能：
https://github.com/yulindian/media-transcriber

先读取仓库 SKILL.md，按照其中的安装参考完成准备和环境检查。
检查是否已有同名技能，保留现有配置与成果。
使用你支持的技能目录；不支持技能安装时，保存到独立文件夹，直接读取 SKILL.md 执行。
不要依赖 Codex，也不要修改我的全局 Python 环境。
```

安装和准备由 Agent 处理。首次转录需要下载识别模型，耗时取决于网络和设备。只下载视频时，Agent 可以跳过语音模型。

## 安装后怎么用

把视频链接附在对应的请求后面。

| 可以直接发给 Agent | 你会收到 |
| --- | --- |
| 用 media-transcriber 只下载这个视频 `<链接>` | 一个视频文件 |
| 用 media-transcriber 只转录这个视频 `<链接>` | 带总结的 Markdown 全文稿、机器原稿、修改记录和字幕 |
| 用 media-transcriber 下载并转录这个视频 `<链接>` | 一个视频文件和上述四份转录文件 |

选择「下载并转录」时，Agent 直接使用已保存的视频进行转录。如果转录中断，可以用同一文件继续。播客、音频和本地录音适合选择「只转录」。

可以粘贴完整分享文案，也可以一次发多条链接。需要指定位置时，加一句“保存到我指定的文件夹”。同一对话中已经明确用法时，后续直接发链接即可。

## 结果是什么样

短内容是一段总结加全文，单人正文直接分段：

```markdown
# 操作教程

## 内容总结
介绍从准备材料、完成操作到检查结果的流程，提醒先验证效果，再批量处理。

## 正文
先准备好材料，再按照步骤操作。完成后，先检查结果是否符合要求。

确认没有问题后，再处理下一批。
```

长访谈可以按话题给时间轴，正文按说话人区分：

```markdown
## 时间轴总结
### 00:00:15–00:10:20｜为什么开始这个项目
讨论需求从哪里来，以及如何先用小版本验证方向。

### 00:10:20–00:23:40｜如何根据反馈调整
比较几种方案，说明取舍和后续安排。

## 正文
**说话人1**：开始时，你最担心什么？

**说话人2**：投入很多时间，却没有解决真正的问题。所以我们先做了小版本。
```

以上为虚构格式示例。每次完成转录会保存最终 `.md`、机器原稿 `.原始.md`、修改记录 `.纠错记录.json` 和字幕 `.srt`。

## 其他 Agent 能用吗

**可以，不依赖 Codex。** 运行脚本不调用 Codex，也不要求 `$media-transcriber` 等特定语法。能读取文件、执行本地命令并联网的 Agent，可直接读取 [SKILL.md](SKILL.md) 按步骤完成任务。`agents/openai.yaml` 只是部分客户端使用的可选展示配置，忽略或移除也不影响转录。

当前实际验证环境为 Windows。安装入口兼容不同系统的路径规则，但尚未在 macOS、Linux 及每一种 Agent 客户端上逐一实测。仅能聊天、不能读写文件或运行命令的 Agent 无法独立执行这套流程。

## 使用前了解这几件事

- **不必默认登录。** 优先尝试公开内容，不自动读取浏览器登录态。部分平台依赖第三方解析服务；失败时可提供有权访问的本地文件。
- **识别不是百分之百准确。** 人名、数字、口音和抢话可能出错。无法确认的内容保留在复核记录中，不靠猜测改写。
- **识别和声音区分在本机运行。** 链接可能发给配置的解析服务；文字校对与总结由当前 Agent 完成，其数据处理方式取决于所用 Agent。
- **转录包含全文和总结。** 识别后，Agent 会继续校对、检查和导出。
- **升级保留个人数据。** 查看[更新记录](CHANGELOG.md)，更新源码时保留配置、模型、任务和成稿。发布标签便于回退。

给 Agent 的入口是 [SKILL.md](SKILL.md)，环境准备见[安装参考](references/installation.md)，常见问题见[使用方案](使用方案.md)。
